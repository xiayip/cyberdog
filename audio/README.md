## 唤醒与抓球成功

A1开机招呼、W1精神唤醒：一声汪，0.35秒（含安静首尾）。
C6抓球成功：「汪！汪汪！」，1.33秒，同一段03号犬吠三次，后两声靠近、音量略增强。
整句没有交替拼接不同狗的声音，也未变调；奶音与汪声仍属于两只不同狗，已逐事件标注。
W2/W3保留困倦与撒娇的奶音梯度。W1触发时不应与B1同时播放，以免叠音。
蓄势C4、急停E3保持静音；A4按唤醒梯度分流，无独立音频。
