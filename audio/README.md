每个代码事件只保留一条推荐声音，共 23 个 WAV。全部取自同一只小狗的真实录音（Freesound / johnnypanic「Puppy」728022–728030，CC0），不变调。

## 格式

- WAV，48kHz，单声道，16bit PCM
- 峰值不超过 0 dBFS，无削波
- 中文文件名，格式为 `<事件>_<场景>.wav`

## 需要代码处理的三处

- **A4** 没有独立音频：按离开时长分流到 W1、W2、W3。
- **C4（蓄势）** 保持静音，让闭爪和成功反馈更突出。
- **E3（异常停止 / 急停）** 保持静音，直到人工复位。

## 抓球成功 C6

「兴奋 → 开心 → 兴奋 → 兴奋」，约 1.51 秒：兴奋起声、开心回应、兴奋双连叫收尾，末尾略增强力度。
