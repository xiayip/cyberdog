# Armie 音频包（奶音 · 哼唧）

给机器小狗的 12 个事件音效 + 6 个动作 × 3 种心情的回应短句，全部是**同一只小狗、同一次录音**里的真实发声（Freesound / johnnypanic「Puppy」pack，728022–728030，CC0）。

## 格式

- WAV，48kHz，单声道，16bit
- 事件音效峰值 −6 dBFS，回应短句峰值 −3 dBFS
- 每条都是完整的一声，只在静音处切，**不变调**

## 命名

文件名统一用中文，规则如下：

```
事件_<含义>_<编号>.wav      12 个事件音效各两条（编号 1、2），播的时候随机取一条
<动作>_<心情>_<编号>.wav    拼好的整句，编号 1 是主版本、2 是另一种说法，随机挑一条播
```

- 事件音效：`事件_开心_1.wav`、`事件_受惊_2.wav` …
- 回应短句：`摸头_开心_1.wav`、`扔球_低落_2.wav` …

|---|---|

| 事件_受惊 | 尖、急 |

## 回应短句（6 个动作 × 3 种心情）

| 动作 | 心情 |
|---|---|
| 摸头 | 开心 / 一般 / 低落 |
| 戳一下 | 同上 |
| 扔球 | 同上 |
| 被拖动 | 同上 |
| 没人理（自言自语，最长 5 秒出头） | 同上 |
| 有人靠近 | 同上 |

心情怎么定（精力/亲密度阈值）不在音频包的范围里。
